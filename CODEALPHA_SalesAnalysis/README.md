# CODEALPHA Sales Analysis Project

## 📊 Project Overview
This project was completed as part of my **Data Analytics Internship at CodeAlpha**.  
The goal is to perform **Sales Analysis** on the dataset to identify revenue trends, product performance, and customer behavior.

---

## 📂 Dataset
- **File:** `sales.csv` (or relevant dataset used for analysis)
- **Columns:**
  - `order_id`, `product_id`, `product_name`
  - `category`, `quantity`, `price`, `discount`
  - `order_date`, `customer_id`, `region`
- **Size:** Contains transactional sales data across multiple categories and regions.

---

## 🛠️ Tools & Libraries
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **Jupyter Notebook**
- **GitHub** (for project documentation)

---

## 🔎 Analysis Steps
1. **Data Cleaning**
   - Converted `order_date` to datetime format.
   - Handled missing values in `quantity`, `price`, and `discount`.
   - Standardized category names.

2. **Exploratory Analysis**
   - Total sales by category.
   - Monthly/quarterly sales trends.
   - Regional performance comparison.

3. **Visualisations**
   - Bar chart: Top categories by revenue.
   - Line chart: Monthly sales trend.
   - Pie chart: Regional sales distribution.
   - Heatmap: Correlation between discount, quantity, and revenue.

---

## 📈 Key Insights
- **Category Performance:** Electronics and Fashion generate the highest revenue.  
- **Seasonality:** Sales peak during festive months (October–December).  
- **Regional Trends:** Urban regions contribute more to revenue compared to rural areas.  
- **Discount Impact:** Moderate
